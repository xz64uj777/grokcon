# Ridge Ore

Open-pit mining company. Start with a claim truck, haul ore, and buy the crew.

Drive with WASD. Realistic controls (the default) let you work each machine's arms, bucket, boom, blade and bed by hand; Simple mode keeps the old "hold Space to dig". See CHANGES.md for the full cheat sheet. V switches machines. The yard office buys machines, ground, blasting charges, and operators, and shows the daily ore prices.

The books save in the browser. The title screen can download or load a copy. Sell ore to fill the contract on the board for a bonus.
