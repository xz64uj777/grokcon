# Ridge Ore

Open-pit mining company. Start with a claim truck, haul ore, and buy the crew.

Realistic controls (the default) are two thumb sticks: you work each machine's arms, bucket, boom, blade and bed by hand. Pull back to reverse. There is no gear shifter. Simple mode keeps the old "hold Space to dig", and that mode also takes WASD. The in-game card and CHANGES.md cheat sheet come from the same control table. V switches machines. The yard office buys machines, ground, blasting charges, and operators, and shows the daily ore prices.

The books save in the browser. The title screen can download or load a copy. Sell ore to fill the contract on the board for a bonus.
